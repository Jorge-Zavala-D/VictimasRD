# Geospatial 2017 metadata

This directory contains non-observation metadata for the 2017 CCPP spatial
milestone:

- `source-checksums.csv` locks the immutable local shapefile components;
- `sample-flow.csv` records aggregate source, conversion, linkage, and
  retention counts generated by the Stata pipeline; and
- `variable-dictionary.csv` defines the 27 spatial fields added to the
  analytical registry.

Row-level data and QA records remain in the configured Dropbox Working area.
See `docs/GEOSPATIAL_2017_PREPARATION.md` for methods and limitations.

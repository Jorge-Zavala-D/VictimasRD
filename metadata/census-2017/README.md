# Census 2017 metadata

This directory contains only non-observation metadata for the Census 2017
integration.

- `source-inventory.csv` records the source role, geography, immutable Dropbox
  location contract, and implemented use.
- `source-ccpp-crosswalk.csv` records 807 source codes: 806 accepted codes map to 802 RUV communities; one code is quarantined.
- `variable-contract.csv` defines the principal analytical variables and
  universes.
- `sample-flow.csv` is regenerated by the authoritative Stata preparation
  pipeline from aggregate QA metrics.
- `historical-to-2017-code-review.csv` is the audit-only comparison ledger
  described below.

Person-, household-, and row-level QA records remain in Dropbox Working. Final
analytical datasets remain in Dropbox Coded. No restricted observations or
identifiers belong here.

## Historical-to-2017 code comparison

`source-ccpp-crosswalk.csv` is the **executable** source-code/RUV map. Data preparation requires exactly one quarantine (`0307080005`, no RUV ID), excludes its 34 people only after raw-delivery accounting, and accepts the other 806 codes mapping to 802 RUV communities. The accepted mapping is not independent evidence that every linked person's origin code denotes the same CCPP in 2017. See the [approved adjudication](../../docs/CENSUS_2017_SOURCE_ADJUDICATION_2026-09-27.md).

`historical-to-2017-code-review.csv` is a **non-executable comparison ledger** created on 27 September 2026. It contains public-geography codes and names only, with no person/household observations or source-specific counts. It compares the executable map with the project-supplied 2007 CCPP directory (`04_census_2007_ccpp.dta` in Dropbox Working), the GeoGPS/INEI 2017 CCPP directory (`07_geospatial_ccpp_2017.dta` in Dropbox Working), and the verified RUV code in the current Coded community registry. Blank flags mean no comparison source was available, not a match.

`directory_consistent_candidate` means code/name agreement across the available directories; it **does not** establish that every person assigned that source code resided in the named RUV community. Other discrepancies still require review. The two explicit former holds have been adjudicated: Ranracancha is accepted by corroborated code and person roster, while Ancahuasi's unsupported Cahuapirhua mapping is quarantined. The comparison ledger itself must never be merged into person data as if it were an executable equivalence.

The [selection and comparability audit](../../docs/CENSUS_2017_SELECTION_AND_CODE_COMPARABILITY_AUDIT_2026-09-27.md) preserves the original concerns; the [approved adjudication](../../docs/CENSUS_2017_SOURCE_ADJUDICATION_2026-09-27.md) records the superseding disposition and remaining limits.

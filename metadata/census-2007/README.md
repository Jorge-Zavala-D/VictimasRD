# 2007 census metadata

This directory contains non-observation metadata for the CCPP-level 2007
census preparation block.

- `variable-dictionary.csv` defines the lean census fields retained in the
  integrated RUV registry and their source universes.
- `sample-flow.csv` is regenerated by
  `code/stata/pipeline/01_data_preparation.do`.

Row-level linkage conflicts and unmatched records remain under Dropbox Working
QA and must not be committed to Git.

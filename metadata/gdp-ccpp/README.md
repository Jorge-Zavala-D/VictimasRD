# CCPP GDP metadata

This directory contains non-observation metadata for the Seminario-Palomino
CCPP GDP milestone:

- `source-checksums.csv` locks the immutable workbook and its logical range;
- `sample-flow.csv` is regenerated by the canonical Stata preparation module
  and records aggregate source, linkage, and retention counts; and
- `variable-dictionary.csv` defines the compact baseline and model-based
  outcome fields added to the final all-row community registry.

The cleaned annual source, district aggregates, accepted linkage table, and
row-level unmatched records remain in the configured Dropbox Working area.
See `docs/CCPP_GDP_PREPARATION.md` for methods and interpretation limits.

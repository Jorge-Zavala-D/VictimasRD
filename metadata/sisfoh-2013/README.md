# SISFOH 2012-2013 metadata

This directory contains non-observation metadata for the SISFOH preparation
section in `code/stata/pipeline/01_data_preparation.do`.

- `source-inventory.csv` fingerprints the immutable Dropbox inputs and records
  their role in the pipeline.
- `variable-contract.csv` documents the principal constructed domains,
  universes, denominators, and interpretation.
- `sample-flow.csv` is generated by Stata from aggregate QA metrics. It contains
  no person- or household-level observations.

Row-level linkage, directory-disagreement, legacy-reconciliation, and unmatched
records remain only in the configured Dropbox Working QA directory. They are
not copied into this repository.

See `docs/SISFOH_2013_PREPARATION.md` for the full source, linkage,
confidentiality, NBI, wellbeing, and interpretation contract.

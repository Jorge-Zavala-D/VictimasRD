# Generated tables

Only appropriately sized, non-sensitive tables generated by versioned code
belong here. Each tracked table must pass disclosure review and have a current
metadata manifest entry identifying its producing script, logical inputs,
specification, software version, generation date, checksum, and paper
destination.

Do not include row-level records, small disclosive cells, or manually curated
Dropbox workbooks.

`rd_outcomes/` contains aggregate machine-readable estimates and LaTeX tables
for the analysis contract, outcome registry, first stage, primary and
secondary 2013 CCPP results, and robustness checks. These products are
generated by `code/stata/pipeline/04a_sisfoh2013_ccpp.do` and remain
`generated_unreviewed` in `metadata/rd-outcome-output-manifest.csv`.

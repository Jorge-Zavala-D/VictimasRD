# Generated figures

Only appropriately sized, non-sensitive figures generated by versioned code
belong here. Each tracked figure must pass disclosure review and have a current
metadata manifest entry identifying its producing script, logical inputs,
specification, software version, generation date, checksum, and paper
destination.

Do not copy historical Dropbox figures here merely because they are small.
Avoid manual edits to generated figures.

`rd_outcomes/` contains the first-stage, primary-outcome RD panels,
standardized-effect forest plot, bandwidth-sensitivity plot, and separate
primary-outcome figures generated by
`code/stata/pipeline/04a_sisfoh2013_ccpp.do`. Their current review state and
checksums are recorded in `metadata/rd-outcome-output-manifest.csv`.
